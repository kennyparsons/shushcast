Workflow

How it works in three steps

01

Install & Start on TV

Install Shush Cast via Downloader code 4756191 or the direct APK on Android TV 10+, launch it, and approve system audio capture.

02

Scan QR Code on Phone

Point any iPhone or Android camera at the on-screen QR code to open the local player page in your mobile browser.

03

Listen in Headphones with Client Volume

Turn the TV volume down or mute it, tap Listen on your phone, and control your own headphone volume directly in the browser.

Capabilities

Built for late-night living rooms

Multiple phones at once

Anyone on your Wi-Fi can scan the same TV QR code simultaneously. Each listener gets their own volume slider and buffer setting.

iPhone Silent-Mode & Home Screen PWA

Audio plays even when the iPhone hardware mute switch is flipped on. Add the player page to your Home Screen for one-tap standalone launch.

50 ms low-latency default

Defaults to a 50 ms lip-sync buffer and lets each phone switch live between 25 ms, 50 ms, and 120 ms depending on Wi-Fi conditions.

Remote button toggle

Includes a headless Shush Cast Toggle launcher activity so remote button mappers can start or stop casting without leaving the show you are watching.

In-app GitHub Releases updater

Check for new versions directly from the TV app and install signed APK updates published on GitHub Releases without touching a USB drive or adb.

100% local LAN

Your TV serves the web player and audio stream directly over your home router. Zero cloud relays, zero accounts, and zero trackers.

Compatibility

What works—and honest OS limits

Supported setup

  • Android TV 10+ (API 29+): Required for Android's built-in AudioPlaybackCapture API.
  • Non-DRM apps & streams: Works cleanly with YouTube, SmartTube, Plex, Kodi, IPTV players, local media, and browser streams.
  • Same local network: Your TV and phones must be on the same Wi-Fi / LAN subnet (client isolation disabled).

DRM restriction

Apps that enforce hardware/OS DRM audio protection—including Netflix and Hulu—explicitly prohibit capture via Android's AudioPlaybackCapture API. When those apps play protected content, Android outputs silence to any capture service. This is an OS-level restriction that no unrooted Android TV app can bypass.
